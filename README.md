# Virtual-piano-bot
![GitHub Release](https://img.shields.io/github/v/release/Durdom55/Virtual-piano-bot)
![GitHub License](https://img.shields.io/github/license/Durdom55/Virtual-piano-bot)
![GitHub Downloads (all assets, all releases)](https://img.shields.io/github/downloads/Durdom55/Virtual-piano-bot/total)


Программа для **автоматического** воспроизведения музыки на виртуальном пианино, в том числе и в **`Roblox`**, написанная с помощью `Python 3.14.7`. Вставьте ноты в текстовое поле, настройте скорость и запустите бота. Поддерживаются **одиночные ноты**, **аккорды** (в квадратных скобках), **паузы** и **т.п.** Управление осуществляется с помощью **горячей клавиши**, есть возможность **сохранения настроек**

>[!WARNING]
>Антивирусы могут помечать exe-файл из релиза как вредоносный - **это ложное срабатывание**. Происходит это из-за отсутствия какой-либо цифровой подписи, так как я компилирую проект через **`auto-py-to-exe`**. Вы можете сами сделать билд проекта, скачав исходный код

## Функции
+ Автоматическое проигрывание музыки
+ Текстовое поле для проигрывания нот
+ Активация по горячей клавише
+ Установка горячей клавиши
+ Настройка скорости
+ Шкала времени, которая отображает степень выполнения текущей мелодии
+ Расширенные настройки
+ Сохранение песен

## Руководство по использованию `Windows`
1. Скачайте exe-файл из релиза проекта или сделайте билд сами
2. Откройте exe-файл и первым делом назначьте горячую клавишу, иначе программа не сможет работать
    1. Нажмите на кнопку **Change HotKey**
    2. В открытом меню нажмите на кнопку посередине - **Click to Set Hotkey**
    3. Нажмите на удобное для вас сочетание клавиш
        1. Если вас не устраивает выбранное сочетание клавиш, нажмите на кнопку **Clear** или повторно на кнопку посередине
    4. Нажмите на зелёную кнопку **Save**, чтобы сохранить горячую клавишу
    5. Нажмите на красную кнопку **Cancel**, чтобы закрыть окно
 3. Назначьте, если надо, скорость, для этого надо двигать ползунок под надписью **Speed: 1x**
 4. Нажмите кнопку **Start**
 5. Нажмите назначенную горячую клавишу, чтобы начать проигрывание мелодии
 6. Чтобы остановить проигрывание, повторно нажмите на горячую клавишу
 7. Чтобы остановить опрос горячей клавиши, нажмите кнопку **Stop**
